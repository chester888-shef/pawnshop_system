Мета. Програма має дозволяти оформити договір під заставу, продовжити його зі сплатою відсотків, визначити суму викупу на задану дату, вести життєвий цикл застави та формувати базові звіти.

Архітектура. Обчислювальне ядро реалізую на C++: оцінка застав, нарахування відсотків з пільговим періодом і пенею, переходи станів застави. Звіти та графічний інтерфейс реалізую на Python (tkinter). Зв'язок між мовами здійснюється через pybind11.

Мінімальний функціонал:

Три категорії застав (ювелірні вироби, техніка, транспорт) з різними правилами оцінки та граничною сумою позики.
Оформлення договору: клієнт, застава, оцінка, сума позики, строк, денна ставка.
Продовження договору зі сплатою відсотків за період.
Життєвий цикл застави: прийнято → продовжено → викуплено / не викуплено → виставлено на продаж → продано. Недопустимі переходи відхиляються.
Нарахування відсотків за фактичні дні з пільговим періодом, пенею після строку та розрахунок суми викупу на задану дату.
Звіти: портфель активних застав, прострочені договори, дохід за період.
Одне вікно GUI з формою оформлення договору, таблицею договорів і кнопкою звіту.

Застосовані патерни. Strategy (правила оцінки), State (життєвий цикл застави), Factory Method (створення застав за категорією), Facade (інтерфейс ядра для Python). Обґрунтування наведено в docs/patterns.md, діаграма класів у docs/class_diagram.md.

## Збірка і запуск

Усі команди виконуються з кореня репозиторію.

```bash
# 1. Віртуальне середовище і pybind11
cd python_app
python3 -m venv venv
source venv/bin/activate
pip install pybind11
cd ..

# 2. Збірка C++ модуля
cmake -S cpp_core -B cpp_core/build -Dpybind11_DIR=$(python -m pybind11 --cmakedir) -Wno-dev
cmake --build cpp_core/build

# 3. Запуск
python python_app/main.py
```

Очікуваний результат:

```
Оцінка: 212.94
Макс. позика: 170.352
Помилка: Invalid jewelry parameters
```

Якщо збірка зламалася, видали `cpp_core/build` (`rm -rf cpp_core/build`) і повтори крок 2.
